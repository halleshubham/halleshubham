## 🚀 Projects
Most of what I build under [ShackyApps](https://shackyapps.in) is open source or self-hostable.

**Products**
- 💬 **[SocioBird](https://sociobird.app)** ([code](https://github.com/halleshubham/sociobird-app)) – schedule and publish to social channels from one calendar; our hosted fork of Postiz.
- 📡 **[StreamBird](https://streambird.app)** ([code](https://github.com/halleshubham/streambird)) – multi-platform live streaming from one browser studio.
- 🏅 **[KudoBird](https://kudobird.shackyapps.in)** ([code](https://github.com/halleshubham/KudoBird)) – thank-you certificates for volunteers and donors, with a public form in Marathi, Hindi and English.
- 📲 **[Botsab](https://github.com/halleshubham/Botsab)** – fair-use WhatsApp API provider server.
- 🗓️ **[Socialize](https://github.com/halleshubham/Socialize)** – social media agentic ecosystem and orchestration platform.
- 📰 **[Shacky CMS](https://github.com/halleshubham/shacky-cms)** – self-hosted headless CMS with DOCX ingest, an AI pipeline, email/WhatsApp campaigns, an MCP server and n8n automation.
- 🤝 **[VolunteerConnect](https://volunteerconnect.shackyapps.in)** – contacts management for social and non-profit organisations.

**Android apps**
- 🎥 **[streambird-android](https://github.com/halleshubham/streambird-android)** – Android client for streambird.app.
- 🐦 **[SocioBirdMobile](https://github.com/halleshubham/SocioBirdMobile)** – mobile app for SocioBird.
- 📞 **[touchbase-app](https://github.com/halleshubham/touchbase-app)** – organise contacts, get reminded to call people, and run a guided call queue.

**Tools and experiments**
- 🧰 **[wp-mcp](https://github.com/halleshubham/wp-mcp)** – WordPress content management MCP server (multi-site, FSE templates, remote HTTP mode).
- 📝 **[JAP](https://github.com/halleshubham/JAP)** – publishes emailed `.doc` attachments to a WordPress site through its API.
- 🧪 **[postiz-saas](https://github.com/halleshubham/postiz-saas)** – a SaaS layer for reselling Postiz.
- 📰 **[Strapazine](https://github.com/halleshubham/strapazine)** and **[wp-headless-magazine](https://github.com/halleshubham/wp-headless-magazine)** – magazine sites on headless Strapi and headless WordPress.
- 🎙️ **[voicetype](https://github.com/halleshubham/voicetype.github.io)** – a simple Chrome plugin for speech to text.
- 🇮🇳 **[DEEP](https://github.com/halleshubham/DEEP)** – write programs in Marathi: it converts them to Python, runs them and translates the output back.
- 🐍 **[PythonUtilities](https://github.com/halleshubham/PythonUtilities)** – scripts for everyday tasks.
- 📊 **[csv-presentation-app](https://github.com/halleshubham/csv-presentation-app)** – present CSV data.
- 🎓 Learning projects: [react-learning](https://github.com/halleshubham/react-learning), [ShackyNotes](https://github.com/halleshubham/ShackyNotes) (React, Redux and DRF), [NodeJsLearning](https://github.com/halleshubham/NodeJsLearning).
